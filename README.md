# IF-CMVC-project
We provide a demo based on Handwritten dataset for our submitted paper: Layer-wise Contrastive Multi-View Clustering with Dynamic Information Flow. Run train.py to show the training process of the model.
## Requirements
python==3.8.10 pytorch==1.11.0 numpy==1.21.5 scikit-learn==1.3.2 scipy==1.10.1 lightly==1.5.18
## Datasets
The Handwritten dataset is placed in "data" folder. The other datasets can be found on the Internet. We will not put the link here.
## Experiment Results
As shown in the paper: Layer-wise Contrastive Multi-View Clustering with Dynamic Information Flow. Run train.py to show the training process of the model.
